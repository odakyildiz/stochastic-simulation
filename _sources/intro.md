# Welcome to Stochastic Simulation

This is an online companion to the lecture notes of the course Stochastic Simulation taught at Imperial College London, Department of Mathematics, by [O. Deniz Akyildiz](https://akyildiz.me).

These pages feature extra explanations and code. Here we aim at reproduce almost every example in the notes in terms of implementation and results.

The lecture notes for the 2024-2025 term can be found from the following link

[[Lecture Notes](https://akyildiz.me/works/simulation_book.pdf)]

Note that the lecture notes are different than last year, so please do not use the old notes.

Please note that this is a work in progress. If you find any errors, please let me know.
